# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and welcoming, give and accept constructive feedback gracefully, and focus on
what is best for the project and its community. Harassment, insults and personal attacks are not
tolerated, in any space of the project.

## Reporting

Report unacceptable behavior privately to a maintainer listed in [`.github/CODEOWNERS`](.github/CODEOWNERS).
Reports are handled confidentially. Maintainers may remove contributions or exclude participants who
break this code of conduct, following the enforcement guidelines of the Contributor Covenant.
