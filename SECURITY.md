# Security policy

## Reporting a vulnerability

Please **do not open a public issue**. Report it privately through
[GitHub security advisories](https://github.com/malo-coet/TelocheSympatoche/security/advisories/new),
with the affected component, steps to reproduce and the impact you expect.

You will get an answer within a week. Fixes are released as soon as possible and credited unless you
prefer otherwise.

## Scope

The parts most exposed are the control API (pairing, authentication of devices, the stream endpoint)
and the extension sandbox (permissions, resource limits). Reports about them are especially welcome.

## Supported versions

Only the latest release receives security fixes.
