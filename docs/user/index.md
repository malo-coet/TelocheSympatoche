# User guide

The user guide is written as features land. It will cover:

- installing the media center on Linux, macOS and Windows;
- adding local folders and network shares, and correcting a wrong recognition;
- browsing and playing movies, series, music and podcasts;
- managing profiles and parental control;
- installing the remote, pairing a phone, and sending media to the TV;
- the accessibility features, and troubleshooting (network, unsupported formats).
